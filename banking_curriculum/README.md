# برنامج تطوير المحاسبة المصرفية — المنهج الدولي العام

حالة المشروع: المرحلة الأولى، الحسابات الجارية (قيود من منظور البنك التجاري التقليدي).

## خريطة الوحدات
1. الحسابات الجارية الدائنة والمدينة (بدأ التنفيذ: درسان في `unit_01_current_accounts.json`).
2. المقاصة والتحويلات الصادرة والواردة: إصدار وقبول، نقدًا وشيكات.
3. تحصيل الشيكات والشيكات المرتجعة والشيكات السياحية (الواقع الحالي والتطبيقات التاريخية).
4. الودائع: تحت الطلب، ادخارية، لأجل، الدورة المستندية والفوائد والتصفية.
5. الاعتمادات المستندية: الاستيراد والتصدير، UCP 600 بحسب نص الاعتماد والعقد.
6. خطابات الضمان: ابتدائية ونهائية، URDG 758 إن أخضعت وثيقة الضمان لها.
7. القروض والتسهيلات: الصرف والسداد والفوائد وIFRS 9 وECL.
8. عرض القوائم المالية للمصارف التقليدية: IFRS 7 وIAS 32 وIFRS 18 وتاريخ نفاذه.

## ميثاق المحتوى
- جميع القيود من منظور البنك، وتُبيَّن قيود العميل عند الحاجة.
- الأمثلة الأصلية للتعليم فقط ولا تفترض دليل حسابات واحدًا لجميع البلدان.
- لا تخلط الودائع (التزامات البنك) مع التسهيلات المسحوبة (أصول البنك).
- لكل درس: شرح مفهوم، دورة مستندية، قيود، حالة رقمية، رقابة، فروق محلية، وأسئلة ذات أربعة بدائل وتفسير.
- لا تنقل نصوص الكتب أو المعايير المحمية حرفيًا.
- ملف التطبيق الأساسي هو `academy_content.json`؛ يُدمج المحتوى بوساطة `scripts/apply_banking_curriculum.py` ويُفحص قبل النشر.
